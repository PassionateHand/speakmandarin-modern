# SpeakMandarinNG — Modern React Website

A modern, responsive redesign concept for SpeakMandarinNG, based on information from the existing website.

## Includes
- Modern premium glassmorphism-inspired UI
- Online / Physical in Abuja tuition switch
- Beginner → Advanced program cards
- HSK preparation, Business Mandarin, Kids & Teens, Travel Mandarin
- Audience sections
- Testimonials and trust statistics
- Consultation / booking form
- FAQ accordion
- Responsive mobile navigation
- Current site image assets referenced from speakmandarinng.org

## Run locally
```bash
npm install
npm run dev
```

## Build for production
```bash
npm run build
```

### Important
The booking form is currently front-end only. Connect it to WhatsApp, email, Formspree, a CRM, or your backend before launch. Confirm current prices, physical-class availability, email address, exact Abuja address, and any claims/statistics with the client before publishing.
